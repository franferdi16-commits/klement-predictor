## 📊 Klement Open Source Predictor - Mundial 2026

¡Democratizando la econometría deportiva! Mientras los analistas tradicionales de traje y corbata se rompen la cabeza con pizarras tácticas, este proyecto replica al 200% el famoso enfoque econométrico de **Joachim Klement** para predecir la Copa del Mundo 2026. 

No compramos humo táctico; corremos simulaciones matemáticas puras basadas en datos estructurales macroeconómicos, demográficos y biológicos.

### 🧠 ¿Qué hace único a este modelo?
* **Curva Parabólica del PIB:** El dinero compra infraestructura, pero la riqueza extrema ablanda el rendimiento deportivo (pérdida del "hambre de gloria").
* **El Límite Biológico de los 14°C:** Penalización absoluta para las selecciones cuyos ecosistemas se alejan del clima óptimo para el desarrollo del futbolista de élite.
* **Ajuste Cultural "Efecto Libertadores" (Nuestra mejora):** La localía no es un número fijo. El modelo mide la resistencia psicológica de los visitantes. Los equipos de la CONMEBOL anulan el bullicio local porque están curtidos en los escenarios más hostiles del planeta.
* **Regresión del Campeón:** Penalización estadística histórica aplicada al campeón defensor.

### 🛠️ Tecnologías Utilizadas
* **Python 3.11**
* **Streamlit** (Para la interfaz interactiva)
* **Scipy & Numpy** (Para correr 10,000 simulaciones de Montecarlo mediante Distribución de Poisson)

# 📊 Klement Open Source Predictor - World Cup 2026

Democratizing sports econometrics! While traditional pundits overanalyze tactical boards, this open-source project replicates and upgrades the macroeconomic forecasting model popularized by strategist **Joachim Klement** for the 2026 World Cup.

We don't buy tactical hype. We run raw mathematical simulations based on macroeconomic, demographic, and biological structural data.

### 🧠 Core Algorithmic Variables
* **Parabolic GDP Curve:** Financial wealth builds top-tier academies, but extreme GDP per capita penalizes performance due to a statistical drop in "sporting hunger".
* **The 14°C Biological Boundary:** Absolute penalty applied to teams whose domestic climate deviates from the perfect temperature required for optimal youth player development.
* **The "Libertadores Effect" Cultural Override (Our custom feature):** Home advantage isn't generic. The system calculates the visitor's psychological resilience. CONMEBOL teams neutralize host crowd noise because they are forged in the most hostile stadiums on Earth.
* **Champion's Regression:** Historical statistical penalty applied to the reigning champion due to success saturation.

### 🛠️ Tech Stack
* **Python 3.11**
* **Streamlit** (For the interactive UI)
* **Scipy & Numpy** (To run 10,000 Monte Carlo iterations via Poisson Distribution)

### 🚀 Quick Start
1. Clone the repo: `git clone https://github.com`
2. Install requirements: `pip install -r requirements.txt`
3. Run the application: `streamlit run app.py`
